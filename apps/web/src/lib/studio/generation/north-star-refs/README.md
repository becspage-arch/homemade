# North-star reference examples

Concrete reference images for the cross-stitch quality bar and the SPECIALIST
design types. Use alongside `../NORTH_STAR.md` and the memory notes
`feedback_cross_stitch_world_class_bar` + `project_cross_stitch_specialist_types`.

**These are competitor product photos (mostly Caterpillar Cross Stitch),
saved for INTERNAL design reference only — never republish them and never copy a
design. They show the *level* and the *device*, not artwork to reproduce.**

## Folders

- **maps/** — MAP designs with location graphics (world map, British Isles), each
  a silhouette with landmarks/icons. SPECIALIST TYPE: landmarks must sit in their
  REAL places; generic fill fails (a worker tried and Scotland came up empty).
- **outline-fill/** — a bold silhouette (deer, pumpkin, tree, Halloween scene)
  FILLED with a curated themed icon set. SPECIALIST TYPE: needs a deliberate,
  legibly-sized icon set, not random confetti dots.
- **typographic/** — hand-lettering designs (e.g. "Positivity"). SPECIALIST TYPE:
  our image→chart converter renders text as gibberish; needs charted lettering.
- **general-bar/** — the everyday quality + VARIETY bar: a wide narrative scene
  (Christmas Wonderland, ~205×118), a cute cottage, a character collection, a
  botanical, a bright tree. Shows the range of size/shape/complexity to match.
