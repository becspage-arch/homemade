**The approach — 2.5D thread strokes (validated, WORKS).** Flat embroidery rendered as real shaded thread strokes on lit woven cloth, NOT 3D path-tracing. The whole engine is ONE primitive: a thread **capsule** splatted with per-pixel fibre shading (Kajiya–Kay anisotropic sheen, subtle ply banding, tube normal, z-buffer crossings). Fabric = warp/weft height-field at z=0; every stitch = capsules at z>0. Accuracy is structural — each stitch primitive emits the *actual* thread it lays (satin's real parallel stitches, a French knot's real coil, chain's real interlocking loops), never a "looks-like" shortcut. The `render/framebuffer.ts` raster (splat + ambientOcclusion + directionalShadow + filmic develop) was adapted from the crochet-era yarn raster — the one piece that carried over.

**Module map:** `core/` (vec, noise, colour — deterministic, no deps); `render/` (framebuffer.ts raster, fabric.ts woven ground, thread.ts materials + ThreadStroke tessellator, scene.ts `renderEmbroidery()` render-only entrypoint); `stitches/` (the library, public surface in index.ts with STITCH_IDS); `contract/` + `compare/` (empty — Phase 2).

**Path-trace learnings (hard-won, don't repeat):** (1) **Geometry hair fuzz does NOT scale** — particle hair on every thread crawled/hung Blender; killed it. Get fibre from the MATERIAL instead (sheen + a noise micro-bump stretched along the strand + roughness-varies-along-fibre). (2) **AgX view transform = real-photo look** (Standard = neon/CGI); AgX mutes colour so add a small compositor saturation (~1.08), not Standard. (3) **Fabric must be visible woven linen** — a white plane blows out to a void; build a warp/weft weave grid (Maximum of two wave bands + slub + weave-dip colour) ~5 threads/cm, organic distortion so it's linen not plastic-canvas; ease the lights so cloth keeps texture. (4) **Threads must sit proud** (fatten ~1.3×) or satin reads flat "clay". Current state: natural linen + realistic floss + soft daylight + dimensional stitches; reads close to a real tester hoop photo. Residual: threads still slightly smooth at extreme zoom; French knots a touch "piped". Real judge = the full Countryside pattern at hero scale (Phase 2).
